# 摩羯座 · Capricorn

SillyTavern 扩展。当前版本 **4.6.0-rc.23.2（精简版）**。

## 安装

将本仓库作为扩展安装，或将文件放入 SillyTavern 的扩展目录；`manifest.json`、`index.js`、`style.css` 均位于插件根目录。重新加载酒馆以应用更改。

## 保留功能

- 拾忆：角色记忆、检索与相关管理功能。
- 声屿：音乐播放器及相关联动。
- CSS 主题库、外观与移动端功能。
- 全局隐藏正则：摘要、随层档案、BGM、导演规划。
- 生成生命周期与上下文清理：保留旧导演规划清理与普通剧情档案逻辑。

## 本版变更

- 完整移除幕间小剧场的交互引擎、入口、样式、示例关卡及开发说明。
- 不再解析或渲染 `<cap-theater>`。旧聊天中遗留的标签内容不会再作为互动界面显示；如不想看到原始标签，请在原聊天中清理或通过自定义仅显示正则隐藏。
- **模型预设需单独关闭/删除剧场生成条目**，否则模型可能继续输出 `<cap-theater>`，插件不会处理。

这次更改仅移除小剧场，不要求删除 `<director>` 导演规划。
